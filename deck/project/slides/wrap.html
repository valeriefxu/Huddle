5 · WRAP

The pitch in four lines

Problem

Friends can’t see who’s free right now.

Solution

A widget with free times, statuses and join-me tags.

v1

Calendar sync, a few statuses, an iOS widget.

Metric

Spontaneous hangouts per active user per week.

Next: a 2-week pilot

3 friend groups, about 15 people.

Measure hangouts per user per week.

Then decide: build v2 or rethink.

Huddle · Pitch

Recap in one breath, then the ask: a small pilot to test the north-star metric before building anything beyond v1. Pilot size is a suggestion; adjust to the people you can actually recruit.
