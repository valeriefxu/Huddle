# Huddle

Know who's free, right now. A friends widget and app that shows where your friends are, when they're free, and what you can do together.

- `prototype/index.html`: clickable phone prototype (single file, open in a browser). Home-screen widget, Now / Plan / Activity / Me tabs, animated friend characters, demo controls.
- `deck/project/`: source files for the 11-slide pitch deck (problem + user, solution, v1 vs later, success metric, wrap + Q&A). `deck.json` is the index, `deck.css` the shared styles, `slides/` one HTML file per slide.
- `tools/chars.py`: generates the static SVG characters used in the deck.

All friends, statuses and calendar data in the prototype are simulated. Targets in the deck (for example 1+ spontaneous hangouts per user per week, a 15-person pilot) are proposals to test, not measured data.
